## コード側の準備

- **`compose.prod.yaml` の api のポートを `127.0.0.1:8000:8000` にした**: そのマシンの中からしか繋がらない。ファイアウォールで閉じるのに加えた二重の守り。手元の Mac の `curl localhost:8000` はこれまでどおり使える
- **web のポートを `${WEB_PORT:-3000}:3000` にした**: `${変数:-既定値}` は compose の変数展開で、`.env` に `WEB_PORT` が無ければ 3000 になる。サーバーでだけ 80 にして `http://<IP>` で開けるようにし、手元の挙動は変えない
- **画面に「デモ用のため、誰でも追加・編集・削除できます」と表示した**: 認証が無く、全員が同じ一覧を共有するため
- **画面に GitHub のリポジトリへのリンクを置いた**: ポートフォリオとして URL だけを渡されても、コードと構成の説明（README・ADR）に辿れるようにするため。`target="_blank"`（別タブで開く）には `rel="noopener noreferrer"` を添える。開いた先のページが `window.opener` 経由で元の画面を書き換えるのを防ぎ、どこから来たか（Referer）も送らない

## Lightsail で選んだもの

| 項目 | 選択 | 理由 |
|---|---|---|
| プラットフォーム | Linux operating system（OS のみ） | 「Linux apps」はアプリ入りのイメージの一覧で、素の Ubuntu は無い。Docker でまとめて動かすので何も入っていない OS が扱いやすい |
| 設計図 | Ubuntu 24.04 LTS | LTS は長期サポート版で、セキュリティ更新が長く出る |
| サイズ | $12・2GB | 1GB だと `next build` でメモリが足りなくなる恐れがある |
| ネットワーク | Dual-stack | IPv6-only だと公開 IPv4 が付かず、見る人の環境によって繋がらない。**GitHub が IPv6 に対応していない**ので `git clone` もできなくなる |
| 自動スナップショット | オフ | 保存量に応じて別料金。コードは GitHub にあり、DB はデモのデータだけなので作り直せば済む |
| インスタンス名 | `todo-fastapi` | Lightsail のリソースは後から名前を変えられない |

料金は時間単位で、$12/月 ≒ $0.017/時間。クレジット 100 ドルで約 8 ヶ月分あり、Free プランの期限（2027年2月4日）の方が先に来る。クレジットへの充当は、請求とコスト管理のクレジット画面で残高が減ることで確かめる（反映は半日〜1日遅れる）。静的 IP はインスタンスに割り当てている間は無料。

### 静的 IP とファイアウォール

- 作成直後の公開 IPv4 は仮のもので、停止・起動のたびに変わる。**静的 IP** を作って割り当てると固定される
- ファイアウォールは初期状態で SSH（22）と HTTP（80）だけが開いている。DB（5432）・API（8000）・web の 3000 番は開けない

## サーバーでの作業

Lightsail の「Connect using SSH」で、ブラウザからサーバーのターミナルに入った。

- **Docker**: 公式のインストールスクリプト（`get.docker.com`）を使った。中で公式の apt リポジトリを登録するので、以降は `apt` で更新できる
- **`docker` グループ**: `sudo usermod -aG docker ubuntu` で `sudo` 無しで使えるようにした。Docker を操作できる＝コンテナを通じてサーバーの何にでも触れるので、実質 root と同じ権限。自分しか使わないサーバーなので利便性を優先した。グループの変更はログインし直すまで反映されない
- **make**: `apt-get install -y make`。git は Ubuntu に最初から入っている
- **リポジトリ**: 公開リポジトリなので、認証無しで `git clone` できる

### `.env` のパスワード

```bash
sed -i "s/^POSTGRES_PASSWORD=.*/POSTGRES_PASSWORD=$(openssl rand -hex 24)/" .env
```

- `openssl rand -hex 24` は 24 バイトの乱数を 16 進数（0-9 と a-f）で出す。**記号を含めないため**。api は接続 URL にパスワードをそのまま埋め込んで組み立てる（`backend/app/core/config.py`）ので、`@` や `/` が入ると URL の区切りと誤解されて繋がらない
- **パスワードを別に控える必要は無い**。サーバーの `.env` がパスワードの置き場所そのもので、SSH で入れば見られる。写しを作ると漏れる場所が増えるだけ
- コンソールから DB を触るときもパスワードは要らない。PostgreSQL の公式イメージは、コンテナの中からの接続をパスワード無しで通す。パスワードが守っているのはネットワーク越しの接続で、今回はそもそも DB のポートを外に開けていない
- `.env` を失くしても、コンテナの中から `ALTER USER` で設定し直すか、デモのデータごとボリュームを作り直せばよい

## デプロイ手順

CD は無いので手作業。サーバーに入って `git pull` → `make prod-up`。モデルを変えたときだけ `make prod-migrate` も流す。README の「公開環境」に書いた。
